セカイ秒読み 統合コンソール
ここにドロップ 台本JSON（.json）／ 素材ZIP（.zip）／ 画像・動画ファイル

GitHub 接続設定

動画の書き出しには ffmpeg・音声合成・ブラウザが要るため、生成そのものは GitHub Actions（GitHubの計算機）で走ります。この画面はそれを操作する管理卓です。

そのためにアクセストークンが要ります。トークンはこのブラウザにだけ保存され、 GitHub以外へは送られません。共用パソコンでは使わないでください。
ワークフローの実行はこのブランチに対して行われます。通常は main。
GitHub → Settings → Developer settings → Fine-grained tokens で作成。
対象リポジトリを kaitai-check だけに絞り、権限は Contents: Read and write と Actions: Read and write の2つだけにしてください。
写真だけはコードで描けないため、この画面から社長のPCのComfyUIに直接 頼みます（Claude Codeは経由しません）。ComfyUIの起動時に --enable-cors-header を付けてください（ブラウザからの直接アクセスを許可する設定です）。
FLUX系は「本体だけ」で配布されていることが多く、その場合は下の3つも選びます
FLUX.1-schnellは蒸留済みモデルのため1〜4ステップで十分（既定は1）。 SDXLなど他モデルに切り替える場合はここも合わせて変えること
設定は必須ではありません。 スマホなど社長のPCのComfyUIに届かない環境では、キーを入れなくても 自動で無料のPollinationsに切り替わって写真を作れます。 Geminiは、そちらより画質を安定させたい場合の有料の選択肢です （キーを入れるとこちらが優先されます）。 キーは Google AI Studio で取得できますが、無料枠だけではほぼ使えず、支払い情報の登録が必要です。
ComfyUIで作らず、既存の実写・イラスト・動画素材をそのまま使いたいシーン向け。各シーンの画面に検索欄が出ます （写真は全種別、動画は`kind: clip`のシーンに出ます）。 Pixabayの利用規約上、 帰属表示なしで商用利用できます。APIキーはこのブラウザにだけ保存されます。 Mixkitなど検索APIの無いサイトの素材は、同じ画面の「手動アップロード」から追加できます。
pixabay.com/api/docs の上部に、無料アカウントでログインすると表示されます。

台本JSONをここにドラッグ＆ドロップ

Claude Code が出力した台本と、Claude Design が出力した素材ZIP（画像・動画）を突き合わせて確認します。

  1. 台本JSON をドロップ（Claude Code の出力）
  2. 「Design用にコピー」で依頼書をコピー → Claude Design に貼る
  3. 返ってきた 素材ZIP をドロップ
  4. 画・文字数・安全領域・チャプターを確認し、この画面で直す
  5. 右の ① 保存 → ② 生成 → ③ 予約投稿 まで、この画面から実行する

読み込んだ内容はこのブラウザに保存され、次に開いたときも残ります。
①〜③を使うには「⚙ 接続設定」でGitHubにつないでください（それ以外の機能は接続なしで使えます）。

① リポジトリに保存

先に「⚙ 接続設定」でGitHubにつないでください。
画面で直した本文・種別・チャプターがそのままコミットされます。

② 動画を生成

先に「⚙ 接続設定」でGitHubにつないでください。
10分の動画で30〜60分かかります。閉じても実行は続きます。

③ 予約投稿

先に「⚙ 接続設定」でGitHubにつないでください。
生成が終わるとDiscordに限定公開のURLが届きます。それを貼ってください。
日付を「おまかせ」にすると、次に空いている19時の枠へ自動で入ります。

サムネイル

写真をタップして選べます。用意した写真・生成画像がここに並びます
1行目の文字にこの語句が含まれていれば、そこだけ赤で強調します
「衝撃」「速報」のような短い煽り文句を、赤いバッジで右上に出せます

BGMの流れ

動画全体の既定BGM
0:00 0:00
    同じ曲が続く区間はひと続きに流れます。変わるところは3秒かけて重ねるので、 切り替わりで音が途切れることはありません。
    BGM素材を追加
    自作アンビエント以外の曲を使いたいときはここから。 YouTube Studio → オーディオ ライブラリ で気に入った曲を探し（フィルタで「帰属表示 不要」を選ぶと表記が要らず楽です）、mp3でダウンロード。 下でそのファイルを選んで名前を付け「追加」を押すと、すぐこのリポジトリに保存されて選択肢に出ます。

      チャプター（概要欄に入るもの）

        画の種別と、実際に出るもの

        種別は「何の画か」と「誰がその画を作るか」の2つで決まります。 シーンごとの今のまま生成すると何が出るかは、 各シーンの種別欄のすぐ下に表示しています。
          図解・位置図・グラフの注意
          この3つは diagram_render.py にそのシーン専用の描画関数を 1つずつ手で書き起こして初めて絵になります。関数が無いシーンは、種別を変えても 本番では文字スライドに落ちます。

          いま関数が入っているのは鬼界カルデラ回だけです。新しい台本で画を持たせたいなら、 種別を「生成画像」に変えてComfyUIで作るのがいちばん早く、 構造をきちんと図で見せたい場合だけ図解の作成を別途依頼してください。

          安全領域

          赤い帯は文字を置いてはいけない範囲です。

          下18% … 字幕帯
          左右11%・上8% … ケンバーンズの寄りで画面外に出る

          デザイン画像でここに文字がかかっていると、動画では切れます。
