GitHub

台本の保存・生成の起動はこのブランチに対して行われます。開発中は claude/manga-youtube-channel-3dvm09、マージ後は main。
GitHub → Settings → Developer settings → Fine-grained tokens。対象を kaitai-check だけに絞り、権限は Contents: Read and write と Actions: Read and write。セカイ秒読みの操作卓と同じトークンで構いません（このブラウザにだけ保存され、どこにも送りません）。

この画面について

サーバーは無く、ブラウザから GitHub の API を直接呼びます。ファイルを開くだけで使えます（スマホなら GitHub Pages に置いたURLを開く）。 台本を直す→保存→生成、ネタから依頼文をコピー、キャラと声の準備状況、週1の検査の記録、ができます。動画の生成そのものは GitHub Actions で走ります。
